# Neovim — шпаргалка

За замовчуванням `nvim` = personal config (`~/.config/nvim`).  
LazyVim: `nvim-lazy` (`NVIM_APPNAME=lazyvim`, `~/.config/lazyvim`).

`<leader>` = **Space** (`␣`).  
Приклади: `␣␣` = Space Space, `␣gs` = Space g s.

Підказка в редакторі: натисни `␣` і почекай — з’явиться **which-key**.

---

## Мої патерни (швидкий копіпаст)

| Клавіша | Дія |
|--------|-----|
| `u` | **undo** — скасувати |
| `Ctrl-r` | redo — повернути скасоване |
| `G` | **jump to end** — кінець файлу |
| `gg` | jump to start — початок файлу |
| `gd` | **jump to definition** — визначення (LSP) |
| `gr` | **show all usages** — усі використання в коді (LSP references) |
| `gI` | go to implementation |
| `ciw` | **змінити все слово** під курсором (change inner word) |
| `cc` / `S` | **змінити лінію** — весь рядок |
| `C` | змінити від курсора до кінця рядка |
| `dd` | видалити лінію |
| `yy` | скопіювати лінію |
| `p` | вставити |

## 1. Швидкий «денний» набір

Запам’ятай спочатку це:

1. `i` / `Esc` — писати / вийти  
2. `hjkl`, `w` `b`, `gg` `G` — рух  
3. `dd` `yy` `p` `u` `.` — базове редагування  
4. `ciw` `diw` `yi"` `ci"` — слова й лапки  
5. `/` + `n` — пошук  
6. `␣␣` — jump to file  
7. `␣e` — explorer  
8. `␣/` — grep  
9. `␣gs` / `␣gg` — git  
10. `␣fp` — projects  
11. `gd` `gr` `K` — LSP  
12. `␣sk` — якщо забув хоткей  
13. `Shift-h` / `Shift-l` — між «вкладками» (буферами)

## 2. Навігація по файлу без мишки

### Як обрати команду

1. **Ціль видно на екрані** → `s` (Flash), введи початок тексту й натисни мітку.
2. **Потрібний символ у цьому рядку** → `f{символ}` або `t{символ}`.
3. **Курсор уже на потрібному слові** → `*`, далі `n` / `N`.
4. **Знаєш потрібний текст** → `/текст`, далі `n` / `N`.
5. **Знаєш номер рядка** → `50G` або `:50`.
6. **Треба прокрутити файл** → `Ctrl-d` / `Ctrl-u`.
7. **Треба повернутися після стрибка** → `Ctrl-o` / `Ctrl-i`.

| Клавіша | Дія |
|--------|-----|
| `Ctrl-d` / `Ctrl-u` | пів екрана вниз / вгору |
| `gg` / `G` | початок / кінець файлу |
| `50G` / `:50` | перейти на рядок 50 |
| `w` / `b` / `e` | наступне слово / попереднє / кінець слова |
| `0` / `^` / `$` | початок / перший текст / кінець рядка |
| `f{c}` / `F{c}` | до символу `c` вперед / назад |
| `t{c}` / `T{c}` | перед символом `c` вперед / назад |
| `;` / `,` | повторити останній `f`/`t` / повторити назад |
| `*` / `#` | наступне / попереднє входження слова під курсором |
| `/текст` | пошук тексту у файлі |
| `n` / `N` | наступний / попередній результат пошуку |
| `s` | Flash: стрибок до видимого тексту |
| `%` | перейти до парної дужки |
| `Ctrl-o` / `Ctrl-i` | назад / вперед по історії стрибків |
| `gd` → `Ctrl-o` | перейти до definition → повернутися |

> Якщо натискаєш `h`, `j`, `k`, `l` або `w` понад 3–4 рази — спробуй `s`, `f`, `/` чи `Ctrl-d` / `Ctrl-u`.

## 3. Вкладки і буфери (навігація)

Зверху показані **буфери** (bufferline), не класичні vim-tabs:

### Буфери (схоже на вкладки зверху)

| Клавіша | Дія |
|--------|-----|
| `Shift-h` / `Shift-l` | попередній / наступний буфер |
| `[b` / `]b` | те саме |
| `␣,` | список буферів (picker) |
| `␣bd` | закрити поточний буфер |
| `␣bo` | закрити інші буфери |
| `␣bb` / `␣\`` | перемкнутись на попередній |

### Вікна всередині вкладки

| Клавіша | Дія |
|--------|-----|
| `Ctrl-h/j/k/l` | між вікнами |
| `␣\|` / `␣-` | split праворуч / вниз |
| `␣wd` | закрити вікно |

Для щоденної роботи майже завжди достатньо **`Shift-h` / `Shift-l`** + **`␣bd`**.

## 7. Редагування: delete / change / yank

У vim операція = **оператор + рух** (або text-object).

### Оператори

| Клавіша | Дія |
|--------|-----|
| `d` | delete (вирізати) |
| `c` | change (вирізати + insert) |
| `y` | yank (скопіювати) |
| `x` | видалити символ під курсором |
| `X` | видалити символ ліворуч |
| `s` | substitute символ (як `cl`) |
| `r{c}` | замінити один символ на `c` |
| `u` | undo |
| `Ctrl-r` | redo |
| `.` | повторити останню зміну |
| `p` / `P` | вставити після / перед |
| `>>` / `<<` | збільшити / зменшити відступ |
| `=` | автоформат (рух/виділення) |
| `gcc` | закоментувати рядок (LazyVim) |
| `gc` + рух / visual | закоментувати діапазон |

### Найпопулярніші комбо

| Клавіша | Мнемоніка | Дія |
|--------|-----------|-----|

| `d$` | | як `D` |
| `d0` | | до початку рядка |
| `dG` | | до кінця файлу |

| `di"` / `da"` | inner/a quotes | всередині / з лапками `"..."` |
| `di'` / `da'` | | те саме для `'` |

## 9. Пошук і заміна

| Клавіша | Дія |
|--------|-----|
| `/текст` | пошук вперед |
| `?текст` | пошук назад |
| `n` / `N` | наступне / попереднє входження |
| `*` / `#` | слово під курсором вперед / назад |

У visual: виділи → `:` → з’явиться `:'<,'>s/...`

## 11. Registers (буфер обміну vim)

| Клавіша | Дія |
|--------|-----|
| `"ayiw` | yank word у регістр `a` |
| `"ap` | вставити з регістра `a` |
| `"+y` | yank у системний clipboard |
| `"+p` | вставити з системного clipboard |

У LazyVim clipboard часто вже зв’язаний із системою — звичайні `y`/`p` можуть працювати з OS pasteboard.

## Нотатки

- Personal (default): `~/dotfiles/nvim/.config/nvim/` → `~/.config/nvim`
  - хоткеї: `lua/core/keymaps.lua`
  - плагіни/модулі: `lua/{ui,editor,lang,lsp,completion}/`
- LazyVim: `~/dotfiles/nvim/.config/lazyvim/` → `~/.config/lazyvim`
  - хоткеї: `lua/config/keymaps.lua`
  - плагіни: `lua/plugins/*.lua`
- Цей файл **не** частина runtime Neovim — це довідка в репі.
